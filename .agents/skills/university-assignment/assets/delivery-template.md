## چیزهایی که نتوانستم تأیید کنم

**این بخش خالی تحویل نشود.** اگر واقعا چیزی نیست، بنویس «موردی نبود» — ولی معمولا هست.

| مورد | چرا تأیید نشد | چه باید کرد |
| --- | --- | --- |
| `[نیازمند داده]` | داده خام در دسترس نبود |  |
| `[نیازمند منبع]` | منبع پیدا نشد |  |
| `[نیازمند تأیید استاد]` | صورت تکلیف مبهم بود |  |
| `[حل نشد]` |  |  |

## منابع

اگر تکلیف ارجاع نخواسته بود، این بخش فقط فهرست منابعی است که **در پیش‌نویس استفاده شده‌اند** — برای اطلاع دانشجو، نه برای چاپ:

- `S1` — `<عنوان>` (`<file:p.12>`)
- `S2` — `<عنوان>` (`<URL>`)

## نکته‌های قالب و نگارش

- قالب خروجی: `<PDF / Word / ...>` — دلیل: `<از خود تکلیف / نبود قالب مشخص>`
- محدودیت حجم: `<رعایت شد / نقض شد — کجا و چقدر>`

اگر محدودیت حجم نقض شد، **حذف پنهانی نکن**: بگو کدام بخش را کوتاه کردی و چه چیزی را قربانی کردی تا جا شود.

## خودآزمایی

### نشانه‌های مصنوعی — روی خود فایل نهایی، نه روی متن مبدأ

```python
import re
COMBINING = re.compile("[ً-ٰٕۖ-ۭ]")   # فتحه کسره ضمه تنوین تشدید سکون الف خنجری
assert not COMBINING.search(mine)            # فقط متنی که خودت نوشته‌ای
```

- [ ] صفر مورد از `COMBINING` در متنی که نوشته‌ام
- [ ] فونت سلول‌ها با فونت بقیه سند یکی است (`w:rFonts/@w:cs` را بخوان، نه `@w:ascii`)
- [ ] صفر نشانه راهنما در فایل تحویلی: نه `نیازمند`، نه `TODO`، نه `پر کنید`، نه `**`
- [ ] صفر فرامتن درون‌سندی: نه «همانطور که در سطر ... نوشتم»، نه اشاره به خود فرایند نوشتن
- [ ] نشانه‌گذاری متناسب با نوع سند (تکلیف ساده ⇒ فقط نقطه، بدون `؛` و بدون `—`)
- [ ] جمله‌ها شکل یکسان ندارند؛ هیچ عبارتی سه بار پشت‌سرهم تکرار نشده
- [ ] PDF نهایی هم بازبینی شده، نه فقط Markdown مبدأ

### درستی محتوا

برای هر مورد، واقعا بررسی کرده‌ای — نه اینکه تیک زده‌ای:

- [ ] هر عدد به منبع یا محاسبه برمی‌گردد
- [ ] هر نقل‌قول عینا از منبع بازیابی‌شده است
- [ ] هر ارجاع باز شده، یا `[نیازمند منبع]` خورده
- [ ] هر فرمول با یک حالت ساده یا یک حد بررسی شده
- [ ] هر نتیجه غیرمنتظره از مسیر دوم هم محاسبه شده
- [ ] واحدها همه‌جا هست و یکدست‌اند
- [ ] نتیجه‌گیری به همان پرسشی جواب می‌دهد که پرسیده شده بود
- [ ] هیچ متن جانگهداری (`[...]`) در بخشی که تمام‌شده اعلام شده باقی نمانده
