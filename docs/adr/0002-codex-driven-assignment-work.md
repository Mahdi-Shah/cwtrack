# اجرای انجام تکلیف توسط دستیار Codex

برای نسخهٔ اول، دستیار در گفت‌وگوی Codex مسئول بررسی سؤال، انتخاب روش، تولید پاسخ و کنترل نتیجه است و پروژه اطلاعات سؤال، منابع، پیشرفت و خروجی‌ها را نگه می‌دارد. این تصمیم از ابزارها و مهارت‌های موجود همین محیط استفاده می‌کند و نیاز به موتور هوش مصنوعی مستقل و اجرای پس‌زمینه را از نسخهٔ اول برمی‌دارد؛ در مقابل، کار پس از بسته‌شدن گفت‌وگو مستقلاً ادامه پیدا نمی‌کند. کاربر پیشنهاد Q7 را پذیرفته است؛ طبق تصمیم Q9، اطلاعات لازم برای ادامه پس از وقفه ذخیره می‌شوند و اصلاح پاسخ نسخهٔ قبلی را حفظ می‌کند.
