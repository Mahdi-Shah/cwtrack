# CLI چندسامانه‌ای با اتصال‌های نام‌دار و ورودی فایل‌محور

فرمان‌های قدیمی CW برای سازگاری باقی می‌مانند و معنای خود را حفظ می‌کنند. مسیر مشترک تازه زیر فرمان‌های حوزه‌ای `account`، `study`، `resource`، `relation` و `work` عرضه می‌شود؛ `cwtrack study` بدون زیر‌فرمان، راهنمای تعاملی مدیریت درس‌ها را باز می‌کند. گزارش یکپارچه از `cwtrack study report` در دسترس است و گزارش‌های legacy با برچسب CW-only مستند می‌شوند.

هر اتصال یک نام محلی دارد. CLI برای انتخاب اتصال نام سامانه و نام محلی را نشان می‌دهد و نام کاربری و شناسهٔ داخلی اتصال را پنهان می‌کند. اتصال‌های قدیمی که نام ندارند در فهرست نام مشتق‌شدهٔ «سامانه · اتصال N» می‌گیرند. اگر نام اتصال برای انتخاب مبهم باشد، CLI باید انتخاب را روشن کند و شناسهٔ خام نخواهد.

فرمان‌ها برای اجرای خودکار گزینه‌های مشخص دارند. متن پاسخ، رمز و شواهد خام در آرگومان‌های فرمان قرار نمی‌گیرند؛ اطلاعات پیچیده از prompt راهنما‌دار یا JSON با `--input-file` گرفته می‌شود. ارجاع فایل خروجی و پیوست با مسیر فایل انجام می‌شود. حذف اتصال و غیرفعال‌کردن پیوند منبع تأیید انسانی می‌خواهد.

CLI چرخهٔ کار تکی و گروهی را مدیریت می‌کند؛ گروه فقط برای اولویت و ادامهٔ کار است. پاسخ، شواهد و تحویل هر تکلیف مستقل می‌ماند و تولید پاسخ مسئولیت Codex است. تحویل نهایی به سامانه همچنان دستی و با بازبینی دانشجو است.

این قرارداد سازگاری استفاده‌کنندگان CW قدیمی را حفظ می‌کند و در عین حال مسیر چندسامانه‌ای قابل‌اسکریپت می‌دهد. شناسه‌های مبهم و ورود متن حساس در shell history منبع خطای کاربر هستند؛ به همین دلیل انتخاب با نام و دریافت دادهٔ پیچیده از فایل انجام می‌شود.
