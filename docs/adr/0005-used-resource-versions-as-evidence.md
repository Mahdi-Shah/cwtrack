# حفظ نسخهٔ منابع استفاده‌شده برای اعتبار پاسخ و بررسی

لینک یا پوشهٔ قابل تغییر به‌تنهایی روشن نمی‌کند پاسخ و کنترل‌های قبلی بر کدام محتوای آموزشی تکیه کرده‌اند. طبق Q22 و Q23، نسخه و محدودهٔ واقعاً استفاده‌شده حفظ می‌شوند؛ تغییر منبع استفاده‌شده نیاز به بازبینی کارهای وابسته را نشان می‌دهد تا بخش‌های متأثر مشخص شوند، در حالی که افزودن منبع جدید خودکار همهٔ خروجی‌های گذشته را نامعتبر یا دوباره حل نمی‌کند. این انتخاب نگهداری سابقه و وابستگی منابع را در برابر سادگی ارجاع به آخرین فایل یا لینک می‌پذیرد تا ادامه و ارزیابی کار قبلی قابل اتکا باشد؛ تصمیم در [طراحی کوئرا و منابع](../quera-and-course-resources-design.md) ثبت شده است.
