# تمرکز قواعد انجام تکلیف پشت Interface کار پایدار

حل در Codex انجام می‌شود، ولی حفظ نسخه‌ها، ادامه پس از وقفه، اثر تغییر سؤال و کفایت شواهد بررسی باید بین مهارت‌ها و داشبورد یکسان باشند. Module `work` این قواعد را با عملیات چرخهٔ کار، فهرست‌خوانی و گروه ثابت مالک است و دریافت شبکه‌ای در Seam جدا می‌ماند؛ قرارداد جاری و وضعیت پذیرش در [طراحی Interfaceها](../assignment-work-interfaces.md) آمده است. جایگزین‌های توابع پراکنده برای هر نوع تکلیف و یک `solve()` خودکار، به‌ترتیب ترتیب و قواعد زیادی به caller تحمیل می‌کنند یا با اجرای حل در گفت‌وگو ناسازگارند؛ در مقابل، این انتخاب قرارداد نسخه‌ها و شواهد را به تعهدی مشترک و قابل آزمون تبدیل می‌کند.
